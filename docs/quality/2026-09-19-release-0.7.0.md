## English

**v0.7.0 · build 605cae6b** was deployed and verified on **2026-09-19** at
`https://clawd-game.whchoi.net/`.

robot without earning progress. The rabbit has long ears, a cotton tail and
front teeth; the robot has a box-shaped body, LED eyes and an antenna.
The selected shape appears in play, portraits, echoes and dash afterimages.

there are ten appearances in total. Existing selections and progress are retained.

character/pose combinations; all ten choices fit at 1440×900, 750×340 and 390×844.

실제 입력으로 기본 캐릭터 세 종을 선택하고 페이지를 새로고침해 저장된 선택과

Chromium 실제 WebAudio 검사는 `CLAWD_BROWSER_TESTS=1`을 지정한 전체 릴리스
검사에 포함했습니다.

리뷰에서 발견한 표현 문제 두 가지를 배포 전에 수정했습니다. 열 가지 선택지가
격자로 줄바꿈되고 안내 문구는 한 행을 사용합니다. 메아리 이름표는 리그의
눌림·늘어남·기울기를 반영해 귀와 안테나 위에 놓입니다. 실제 캔버스 비교에서
캐릭터·동작 조합 12개의 몸체 가림은 0픽셀이었고, 1440×900·750×340·390×844
화면에서 열 가지 선택지가 모두 가로 범위 안에 들어왔습니다.
기존 고양이 외형 픽스처는 유지했습니다.

API 검증에는 임시 플레이어 한 명을 사용했습니다. 접수·동일 기록 재제출의
멱등성·메아리·개인 기록 조회·변조한 주장 값의 거절을 확인한 뒤, 해당
플레이어가 만든 네 행만 조건부로 삭제하고 보드 카운터 증가분을 되돌렸습니다.
일관된 읽기로 삭제를 확인했고 메아리는 404를 반환했습니다. 스모크가 의도한
텔레메트리 오류와 오프라인 네트워크 오류를 제외한 예상 밖 문제는 0개였습니다.
