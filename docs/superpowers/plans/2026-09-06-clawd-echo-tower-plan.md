# CLAWD JUMP: ECHO TOWER — implementation plan

> **For agentic workers:** this plan is executed as parallel workflow agents (one per task below). Each agent reads the spec, this plan, and the contract files, implements ONLY its files, and proves its work with `npx vitest run test/<area>` plus `npx tsc --noEmit -p tsconfig.json` filtered to its files. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A Clawd Jump successor whose deterministic simulation runs both in the browser and on an ECS Fargate server, giving verified leaderboards, ghost "echoes" and a server-seeded daily tower, deployed as CloudFront → prefix-list-locked ALB → Fargate.

**Architecture:** `src/sim` is an environment-free TypeScript engine stepping one input-mask byte per 1/120 s tick. `src/client` renders and sonifies sim state and records the mask log; `src/server` (Fastify) serves the built client and replays submitted logs with the same sim to verify claims before writing DynamoDB. `infra/` is one CDK stack.

**Tech Stack:** TypeScript 5.9, esbuild, vitest, Fastify 5, zod, AWS SDK v3 (DynamoDB), AWS CDK 2.268, Node 22 (container) / 20 (host), Playwright (smoke).

**Spec:** `docs/superpowers/specs/2026-09-06-clawd-echo-tower-design.md`

## Global constraints (verbatim from the spec)
- `src/sim` imports nothing from DOM, Canvas, WebAudio or Node. Uses only `src/sim/dmath.ts` math (no `Math.sin/cos/tan/exp/pow/hypot/atan2/random`, no `Date`).
- Tick `DT = 1/120`; input is one byte per tick with bits `LEFT=1 RIGHT=2 UP=4 DOWN=8 JUMP=16 DASH=32`; press edges are computed inside the sim from the previous tick's mask.
- Feel constants come from `src/sim/config.ts` `PHYS` and are not retuned.
- Grid / spawn legend is `src/sim/legend.ts`. Geometry rules: shafts 4 tiles wide, shaft walls stop 2 tiles above the floor, never enclose a region, no pit wider than 7 tiles.
- UI text is Korean; code, comments and docs are English. Fonts: Outfit + Noto Sans KR from Google Fonts (the only external fetch).
- Every glyph the player reads is DOM; only the world is `<canvas>`.
- ALB SG ingress is only the CloudFront origin-facing prefix list; listener default action 403; forward only when `X-Origin-Verify` matches the Secrets Manager token (dynamic reference, never plaintext).
- Contracts are authoritative: `src/sim/types.ts`, `src/sim/legend.ts`, `src/sim/config.ts`, `src/sim/level.ts`, `src/sim/replay.ts`, `src/sim/index.ts`, `src/shared/biomes.ts`, `src/shared/protocol.ts`, `src/server/types.ts`, `src/server/repo/types.ts`, `src/client/contracts.ts`. Change a contract only if implementation proves it impossible, and then record the change in your final report.

### Task A — Simulation engine (`src/sim`)
**Files:** create `src/sim/sim.ts`, `src/sim/player.ts`, `src/sim/entities.ts`, `src/sim/foes.ts`, `src/sim/gen/daily.ts`, `src/sim/gen/endless.ts`; tests in `test/sim/*.test.ts`; fixture `test/fixtures/levels.ts` (a 40×14 flat test room, a 4-wide shaft room, a pit room).
**Interfaces:** consumes contracts above. Produces `class Sim` with `constructor(def: LevelDef, opts?: SimOptions)`, `readonly level: Level`, `readonly def`, `readonly state: SimState`, `step(mask: InputMask): void`, `drainEvents(): SimEvent[]`, `summary(): RunSummary`, `get finished(): boolean` (cleared, or tide 'over'); `makeDailyLevel(seed): LevelDef` (finite tower, ~150 rows, `tide: true`, goal at the summit, id `'daily'`, biome rotates every 50 rows via row bands; the biome field is the bottom band); `makeEndlessLevel(seed): LevelDef` (560 rows, id `'endless'`).
Behaviour (port from reference `player.js`, `world.js`, `entities.js`, `enemies.js`): coyote/buffer, asymmetric gravity + apex window, turn boost, corner correction, 8-way dash with `dashEndSpeed`, wall slide/jump with lock, stomp + stomp bounce + shockwave, springs, one-way platforms, moving platforms carrying the player, saws, updrafts, water, crumbling tiles, checkpoints, shards/relics with combo, goal → `phase 'clear'`, death → `'dying'` → respawn (story) or `'over'` (tide), hp 3 with knockback/invuln, foes: walker, hopper, flyer, turret (+bolts), chaser, spiker. New: dash crystal (`D`: on touch while `!dashReady || jumps>0` → refill dash and reset air jumps; `state = crystalRespawn`; counts down to 0 = visible again); switch toggle (`k`: dashing through it flips `level.switchA`; 0.3 s cooldown; a player standing inside a block that becomes solid is nudged up by up to 1 tile or hurt); tide (`def.tide`): `TideState` per PHYS tide constants, kills on contact, `tideOver` event and `phase 'over'` after the death animation.
Determinism: all randomness via `makeRng(opts.seed ?? def.seed)`; per-tick `time += DT` only in `'play'`.
**Tests (write first):** same masks twice → `JSON.stringify(state)` identical at ticks 600/3600/7200; a held JUMP from standing rises 2.5–2.9 tiles and lands; a 1-tick JUMP tap rises less than a held one; DASH right on flat ground travels 40–50 units by dashEnd; a 4-wide shaft can be climbed by alternating JUMP with LEFT/RIGHT held toward each wall; stomping a walker kills it; crystal restores dash mid-air; `k` toggles `switchA` and `%`/`&` solidity flips; tide kills and finishes the sim; `verifyReplay` round-trips a recorded run and rejects a tampered `ticks`.
- [ ] tests → fail → implement → pass → `git commit -m "feat(sim): deterministic engine"`

### Task B — Levels DSL and the nine zones (`levels/`, `src/sim/levels.generated.ts`)

Validation (`validate`) must reject: non-rectangular rows, missing `P`/`G`, any `o`/`R`/`G` not reachable by flood fill from `P` over non-solid cells (treat `%` as solid and `&` as passable, then the reverse, and accept if reachable in either polarity), a bottomless gap wider than `MAX_PIT_TILES`, a shaft (two vertical walls ≥ 5 tall facing each other across an empty interior) narrower than 3 or wider than 5.
Content: `t1` teaches run/jump/double jump (par 45, 20 shards), `t2` dash + springs + water (par 55), `t3` wall jump shaft + relic (par 70); `s1` crumble + moving platforms + rain (par 60), `s2` switch blocks + toggles (par 75), `s3` turrets + saws + chaser (par 90); `v1` dash crystals chain over a pit field (par 70), `v2` updrafts + flyers + one-way maze (par 85), `v3` finale mixing everything, 2 checkpoints (par 120). Each zone 60–120 columns × 16–30 rows, 18–32 shards, exactly 1 relic, ≥ 1 checkpoint from t2 on, Korean `name` and one-line Korean `hint`.

### Task F — Input (`src/client/input`)
**Files:** create `src/client/input/input.ts` (`class Input implements InputPort`), `binds.ts` (`DEFAULT_BINDS`, `PAD_MAP`, `keyLabel`), `index.ts`.
Semantics: DOM key events are queued and drained in `poll()`; `held()` reflects keys down after the drain; `takeLatched()` returns bits pressed since the last call (edge even if released within the frame); `takeMenu()` yields edge actions; gamepad polled in `poll()` (sticks with 0.35 deadzone, d-pad, PAD_MAP); touch from `TouchState` (`jumpPressed`/`dashPressed` consumed into latched); `blur` releases everything; owned keys `preventDefault`.
**Tests:** `test/client/input.test.ts` with a fake `window` (`addEventListener` capture) — keydown+keyup within one frame → `takeLatched()` has JUMP, `held()` does not; held key → `held()` has bit every frame, `takeLatched()` only once; rebinding moves a key; blur clears.

### Task G — Server (`src/server`)
**Files:** create `src/server/app.ts` (`buildApp(deps): Promise<FastifyInstance>`), `routes/health.ts`, `routes/daily.ts`, `routes/runs.ts`, `routes/leaderboard.ts`, `routes/ghost.ts`, `daily.ts` (`dailySeed(date, secret): DailySeed` — HMAC-SHA256 via `node:crypto`, first 4 bytes as uint32), `runs.ts` (submission service: decode masks → `verify(def, replay, claim)` → eligibility (assist → reject 'assist'; daily: `date` must be today or yesterday UTC, `seed` must equal `dailySeed(date)`; story: `levelId` must exist in `LEVEL_BY_ID`) → `boardScore` → PB check → `repo.saveBest`), `repo/memory.ts`, `repo/dynamo.ts` (single table, `TransactWriteItems` in `saveBest`, `Query` with `ScanIndexForward` for `topRuns`, `Select: COUNT` for `rankOf`), `static.ts` (`@fastify/static`, `/assets/*` immutable, `index.html` no-cache, SPA fallback only for `/`), `index.ts` (production wiring from env `PORT`, `TABLE_NAME`, `DAILY_SECRET`, `STATIC_DIR`, `APP_VERSION`).
