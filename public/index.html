데이터 안내

순위표에 올릴 때 서버에 남는 것

  • 구역을 돌파하거나 데일리 타워를 오른 뒤 순위표에 올릴 때만, 입력 기록(리플레이)·기록 시간·파편·쓰러진 횟수·표시 이름·이 기기가 만든 익명 플레이어 id가 서버에 저장된다.
  • 순위표에는 이름과 기록만 보인다. 플레이어 id는 공개되지 않고 서버가 만든 12자리 태그가 대신 표시된다.
  • 보조 모드 기록은 보내지 않는다.

플레이 통계로 보내는 것

  • 화면 전환, 구역 시작·돌파·나가기, 쓰러진 위치(타일 좌표)와 원인, 프레임 시간, 오류 메시지.
  • 기기 종류(iOS·Android·데스크톱), 화면 배율, CPU 코어 수, 처음 실행한 뒤 지난 날의 구간(0·1·2-6·7+일).
  • 실행마다 새로 만드는 무작위 세션 번호만 붙는다.

다른 기기로 옮길 때

  • 설정 → 데이터 → 다른 기기로 옮기기를 누르면 이 기기의 진행도(구역 기록·별·데일리 기록·플레이어 id·이름)가 리플레이 없이 서버에 7일 동안 보관되고, 8자 코드는 한 번 쓰면 사라진다.

보내지 않는 것

  • 플레이어 id와 이름은 플레이 통계에 절대 넣지 않는다. IP 주소는 서버 기록에도 남기지 않는다.
  • 계정·이메일·연락처·광고 식별자를 모으지 않는다. 쿠키를 쓰지 않는다.

지우기

  • 이 기기의 기록은 설정 → 데이터에서 지울 수 있다.
  • 서버에 올라간 기록을 지우려면 아래 기록 번호를 적어 GitHub 이슈나 이메일로 요청한다. 플레이어 태그는 이 기기에서 계산할 수 없어 기록 번호로 찾는다.
